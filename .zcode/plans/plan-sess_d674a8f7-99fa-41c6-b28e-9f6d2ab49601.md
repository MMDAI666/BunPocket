## 目标

1. 分类图标支持三种类型：**图标库（SVG）、emoji、自定义图片** —— 系统分类默认用图标库，用户可显式改选 emoji 或图片，也可恢复默认；页面操作按钮等常规 UI 不再用 emoji。
2. 顶栏：设置/统计/搜索图标统一为图标库 SVG，解决齿轮小且不协调。
3. 搜索框：字号调小、宽度收缩为"图标+文字提示"长度、靠右。
4. 预算卡：去掉重复的"月预算"标题。

图标库选用 **lucide-react**（线性 SVG，与简洁渐变风格统一，tree-shakable；项目目前无任何图标库）。

## 修改内容

### 1. 安装依赖
`npm install lucide-react`

### 2. 数据库迁移：新增 `icon_type` 字段（三种类型的显式建模）
- 新建 `src-tauri/migrations/002_category_icon_type.sql`：
  `ALTER TABLE category ADD COLUMN icon_type TEXT NOT NULL DEFAULT 'auto';`
- `src-tauri/src/lib.rs` 注册 version 2 迁移。
- 取值与渲染规则：
  - `auto`（存量数据默认值）：系统分类（有 name_key）→ 显示图标库 SVG；自定义分类 → 显示 emoji 字段。**存量数据无需回填**，安装即生效。
  - `emoji`：用户显式选了 emoji，强制显示 `icon` 字段（可覆盖系统分类的库图标）。
  - `image`：用户设置了自定义图片，显示 `icon_image`。

### 3. `src/db.ts`
- `CategoryRow` / `Category` 增加 `icon_type` 字段；`insertCategory` 增加该参数；`updateCategory` 的 patch 白名单加入 `icon_type`。

### 4. 新建 `src/lib/categoryIcon.tsx`
系统分类 `name_key` → lucide 图标映射（22 个）：餐饮→Utensils、交通→TrainFront、购物→ShoppingBag、日用→Package、娱乐→Gamepad2、医疗→Pill、住房→House、通讯→Phone、水电燃气→Zap、学习→BookOpen、数码→Smartphone、服饰→Shirt、零食→Candy、水果→Apple、保险→ShieldCheck、红包→Gift、工资→Briefcase、奖金→PartyPopper、理财→TrendingUp、兼职→Wrench、退款→Undo2。

### 5. 改造 `src/components/ui/IconBadge.tsx`（全局唯一图标渲染出口）
新增 `nameKey` / `iconType` props，渲染优先级：
`icon_type==='image'` 的图片 → `icon_type==='emoji'` 的 emoji → nameKey 映射的 SVG（auto 的系统分类）→ 图片回退 → emoji 回退。
SVG 单色 `text-ink-2` 衬现有 `bg-chip` 圆底，尺寸随 sm/md/lg 为 16/20/24px。
六个使用页（Home/Bills/AddBill/Budget/Stats/Categories）的调用点补传 `nameKey={cat?.name_key}` `iconType={cat?.icon_type}`。EmojiPicker 保留（选 emoji 是三种类型之一）。

### 6. 分类编辑页 `src/pages/Categories.tsx`
- 选 emoji 时：`updateCategory({ icon, icon_image: null, icon_type: "emoji" })`（341 行）。
- 上传图片时：`updateCategory({ icon_image, icon_type: "image" })`（141 行）；新增分类的 insert 调用同步传入。
- 换图标 Sheet 里增加"恢复默认图标"按钮（仅系统分类显示）：`updateCategory({ icon_type: "auto" })`，i18n 补 `categories.resetIcon`（zh/en）。
- "🖼 从相册选择" 按钮的 emoji 前缀换成 lucide `Image` 图标（常规操作不用 emoji）。

### 7. Home 顶栏（`src/pages/Home.tsx` 141–167 行）
- ⚙ → `<Settings size={20}/>`、📊 → `<ChartColumn size={20}/>`，按钮保持 h-9 w-9，删除 `text-lg`。
- 搜索按钮：去掉 `flex-1` 与 `min-w-0`，加 `ml-auto` 靠右紧挨统计图标；`h-9→h-8`、`text-sm→text-xs`、`px-4→px-3`、gap 收紧，内部用 `<Search size={14}/>`，宽度自然收缩为"图标+搜索账单"长度。

### 8. 预算卡去掉"月预算"标题（`Home.tsx` 193–195 行）
删除 h2 及下方 `mt-1`（201 行），内容垂直居中；若 `home.monthlyBudget` 全局无其他引用则从 zh-CN/en-US 语言包清理。
