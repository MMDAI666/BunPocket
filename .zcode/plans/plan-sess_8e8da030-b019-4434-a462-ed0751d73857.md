# 统计页环图：修复入场动画 + 单击下穿子分类

## 一、环图入场动画修复（问题1）

根因分析（已定位两个嫌疑，按序修）：
- 环图被 `shares.length===0 ? 暂无数据 : <Chart/>` 条件挂载（Stats.tsx:410），Chart 在数据就绪后才 mount，init 与带数据的首次 setOption 同帧——冷启动首渲路径的入场动画在 Android WebView 上没有播出。同页柱状图/折线图无条件挂载、走"空→有"的 setOption 更新路径，动画正常（此前已验证）。
- Chart.tsx 的 ResizeObserver observe 初始回调会立即触发一次 `chart.resize()`，可能打断进行中的入场动画。

修复：
1. **Chart.tsx**：resize 防护——回调里比较 `container.clientWidth/Height` 与 `chart.getWidth()/getHeight()`，仅在尺寸真实变化且非 0 时才 resize。
2. **Stats.tsx**：环图 Chart 改为常挂载（与柱状图同路径）：`data===null` 加载期渲染空 option 的 Chart，数据到达走 setOption 更新动画；"暂无数据"文案只在图例区显示，不再卸载 Chart。
3. pie series 显式动画配置兜底：`animationDuration: 600, animationType: "expansion", animationDurationUpdate: 300`。

## 二、单击下穿（问题2，用户已定：单击触发；本级账单参与占比）

1. **Chart.tsx 增加事件通道**：新增 `onEvents?: Record<string, (params) => void>` prop；挂载时一次性注册 `chart.on(name, dispatch)`，dispatch 从 ref 读最新 handler（避免重绑丢事件）；卸载 off。
2. **src/lib/category.ts 新增 `rollupByNode(bills, node, kind)`**：对 node 每个未隐藏直接子分类用现成 `subtreeIds` 求和，外加"记在 node 本身"的一桶；返回与现有一致的 `{cat, cents}[]` 结构（本级桶的 cat 即 node 自身）。根级仍用 `rollupByTopLevel`。
3. **Stats.tsx**：
   - 新状态 `drillPath: Category[]`（`[]`=根级）；shares 按层级分支计算；**顺带修存量 deps bug**（Stats.tsx:123 `dailyKind`→`shareKind`，否则切收支占比不重算）。
   - pie data 项携带 `catId`（ECharts click params.data 取，不做名字匹配）；扇区单击与图例行单击统一走 `drill(entry)`：仅当该分类有未隐藏子分类时下穿 push，叶子分类无操作。
   - 面包屑「全部 › 餐饮 › 零食」（照搬 AddBill.tsx 样式），点击截断返回；下穿时显示在占比卡片标题行下。
   - 中心 graphic 文字：根级=总支出+总额；下穿=该分类名+子树总额。
   - 状态联动：`shareKind` 切换重置 drillPath；月份/年份切换保留；showAll 沿用。
4. **i18n**：`stats.all`（全部/All）词条；zh/en 同步。

## 三、构建与真机验证

1. 纯前端改动：`pnpm build` → `pnpm tauri android build --debug` → adb 安装真机。
2. CDP 驱动验证：进入统计页后快速连拍 2-3 帧确认环图扇区展开动画可见；单击「餐饮」扇区/图例 → 下穿出 零食/水果/外卖/餐饮本身；点面包屑返回；收入侧同样抽验；切月份下穿保持、切收支重置。
3. 截图目检用 general-purpose-flash agent（用户指定）。
